# Cloudy — Cloud Hosting Landing Page

A modern, responsive landing page for a fictional cloud hosting service called **Cloudy**. Built with pure semantic HTML5, CSS3, and optimized for high performance, accessibility, and SEO.

---

🛠️ Features
- **Semantic HTML5:** Clean layout structure using `<header>`, `<nav>`, `<section>`, and `<footer>`.
- **CSS Grid & Flexbox:** Multi-column responsive card layouts and modern flex alignments.
- **CSS Custom Properties:** Centralized color schemes and spacing variables via `:root`.
- **Fully Responsive:** Mobile-first media queries tested across mobile, tablet, and desktop breakpoints.
- **Smooth Navigation:** Page anchors with native smooth-scrolling.
- **Vector Icons:** Integrated via Font Awesome CDN.
